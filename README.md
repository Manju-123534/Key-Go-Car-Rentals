# KeyGo Car Rentals

A responsive self-drive car rental landing page for KeyGo, inspired by the browsing and booking flow on Revv's car-rental page.

## Run locally

Open `index.html` in a browser. The booking search, vehicle filters, favourites, mobile navigation, and sign-in preview are front-end interactions. Booking and account services are not connected to a backend yet.

## Project reference

The supplied `rea-main.zip` is the separate [REA: Reverse Engineer Anything](https://github.com/morluto/rea) developer toolkit. It is not the KeyGo rental website source, so this repository links to the upstream project instead of copying its 8,000+ tooling files into the rental app.

## Inspiration

The layout takes cues from [Revv Car Rental](https://www.revv.co.in/car-rental): a location and date search, popular vehicle cards, service benefits, and FAQs. KeyGo uses its own brand, copy, and styling.
